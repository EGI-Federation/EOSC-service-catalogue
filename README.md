# EOSC EGI Node Service Catalogue

A simple FastAPI implementation of the EOSC Service Catalogues as described in
[Registration of EOSC Service Catalogues in the EOSC EU Node](https://zenodo.org/records/18622838)

Takes some code from [EEN repo](https://github.com/EOSC-Lot-1/eosc-service-catalogues-specs/)
to ensure consistency with the model of the EEN
